## Remaining nonblocking beta risks

1. **Manual type remainder:** 99 of 144 registered base types did not receive deep individual pixel
   review, although all 1,115 indexed examples opened successfully. Beta telemetry is intentionally
   absent, so user reports and an external real-world corpus remain important.
2. **Browser scope:** automated runtime coverage is Chromium-only under WSL2. Firefox, WebKit/iOS,
   and browser-specific HTTPS-to-loopback/private-network behavior remain platform follow-ups.
3. **Native platforms:** Windows received an MSVC cross-compile check for the Companion
   server/backend only; the Tauri wrapper was not Windows-compiled or runtime-tested. macOS was not
   built or run. NTFS replacement and Windows/macOS tray and watcher behavior remain open.
4. **Linux desktop integration:** WSLg had no real GNOME/KDE panel. An isolated XEmbed host covered
   application tray/menu logic, not real panel placement or login/autostart. The `.deb` was extracted,
   not installed, so maintainer/install/uninstall behavior is untested.
5. **Package visual provenance:** picker/tray screenshots are from the immediately preceding locked
   package. The exact final package was separately launched and proved for identity, listener,
   config, and watcher SSE; its only intervening source delta was non-UI watcher retry logic.
6. **Companion trust model:** loopback and browser Origin/token checks do not isolate other programs
   on the same machine. The token is intentionally obtainable from `/ping`; the UI/README disclose
   this machine-wide local trust boundary.
7. **Fixture/renderer limits:** FITS and DICOM contain real synthetic pixel planes but their viewers
   currently expose metadata rather than image pixels. The APK is a valid unsigned structure fixture,
   not an installable app claim; the DICOM is coherent Part 10 data, not full CT-IOD certification.
8. **Accepted low visual issues:** at 390 px the PSD Layers pane obscures the trailing 100×100 status
   readout, while the composite and controls remain usable. Optional base Dockerfile/Compose summaries
   concatenate a few labels and values. WSLg GTK picker captures contain documented compositor/portal
   artifacts that should be rechecked on a normal Linux desktop.
9. **Evidence retention:** the 10 supplementary renderer images were inspected by both root and the
   independent reviewer but do not have a separate per-image review JSON. The 148 primary format,
   workflow, offline, and package images are checksum-ledger-bound. The entire evidence directory is
   intentionally untracked, so it must be preserved or archived before any future `git clean`.

Companion critical paths pass; same-origin and destructive/auth/path negative tests are clean;

audited beyond normal examples; and the exact full repository gate is green.
