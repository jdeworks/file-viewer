# Stage 7 — Identity Arbiter

**Genre:** detective / deduction. **Theme:** several entities all claim the same name.
You are the arbiter — gather evidence and decide who is real.

## How to play

Work through **seven substages**, each a different proof:

1. **Credential scan** — flag the field on a dossier that contradicts a known fact.
2. **Duplicate test** — diff two tied dossiers and find the tampered field.
3. **Timeline audit** — mark the one log entry that is logically impossible.
4. **Reference chase** — open the referenced **anchor record** in the viewer to break
   a credential chain.
5. **Duplicate roster** — open the system files, **pin** evidence, and accuse the
   duplicate with a full **triad** (entity + claim + source fact).
6. **Quorum ghost** — exonerate the innocent, then expose the liar by **searching** the
   session ledger.
7. **Final commit** — name the true holder.

## Controls

- **Click** candidates and fields; use the **flag / diff / mark** buttons.
- **Open (and sometimes search) real files** in the viewer to mint evidence-board facts.
- **Pin** facts, assemble an **accusation triad**, then **commit** your judgment.

## The boss — The Name Collision

Two entities stay tied on paper. The documents can't separate them — but a photo can.

> **Un-cheat hint:** open Entity F's **image** in the viewer, then open its **Metadata
> pane** and read the **GPSInfo** row. The picture knows where it was taken, and that
> location is outside any layer it claims. Eliminate the impostor, then commit to the
> real holder.
