# v86 — x86 PC Emulator

> Run legacy x86 operating systems (DOS, Windows 95, Linux) in the browser via v86 WASM emulation.

## Format Details

| Field | Value |
|-------|-------|
| Extension(s) | `.img`, `.ima`, `.iso`, `.vhd`, `.qcow2` |
| MIME type | `application/octet-stream` |
| Binary / Text | Binary (raw disk images) |
| Created by | v86 project (copy86.com) |
| Common use | Running legacy x86 OS images in the browser; DOS, Windows 95/98, small Linux distros |
| Spec / Docs | [v86 GitHub](https://github.com/copy/v86) |

## Capabilities Matrix

### View / Run
| Capability | Status | Notes |
|------------|--------|-------|
| Full x86 CPU emulation | ✅ | WASM-based v86 core |
| VGA text and graphics output | ✅ | Both text-mode and VESA graphics displayed |
| Keyboard input | ✅ | Full keyboard pass-through to emulated OS |
| Floppy image support | ✅ | `.img` floppy disk images |
| HDD / CD-ROM image support | ✅ | Raw `.img` / `.ima` disks and `.iso` optical images |
| Safety gate | ✅ | Explicit consent prompt before starting the emulator |
| Pause / resume | ✅ | Toolbar toggles the running emulator |
| Save / load state | ✅ | Save downloads `.v86state`; load restores from a picked state file |
| Fullscreen | ✅ | Browser fullscreen request for the emulator screen |
| Boot time | ⚠️ | Varies by OS image; small Linux distros boot in seconds |

## Known-File Enhancement

No known-file plugin — all disk images use the same v86 emulator.

## Real-World Examples

- [`sample.img`](../examples/sample.img) — DOS boot floppy demonstrating v86 emulation and VGA text mode

## Known Limitations

- Large disk images (>100 MB) have long load times as the image is fetched entirely before boot
- Network card emulation is not wired up; network-dependent OSes have no connectivity
- Mouse support varies by OS and guest driver availability
- `.vhd` and `.qcow2` are detected for routing, but compressed/sparse disk formats may not boot unless v86 can consume the bytes directly
