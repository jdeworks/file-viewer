# MT940 Bank Statement

> MT940 SWIFT bank statement viewer — account reference, opening/closing balances, currency, and transaction list.

## Format Details

| Field | Value |
|-------|-------|
| Extension(s) | `.mt940`, `.sta`, `.txt` |
| MIME type | `text/plain` |
| Binary / Text | Text (SWIFT field syntax) |
| Common use | Bank statement exports from SWIFT-compatible banking systems |

## Capabilities Matrix

### View
| Capability | Status | Notes |
|------------|--------|-------|
| Statement reference | ✅ | `:20:` reference field |
| Account number | ✅ | `:25:` account identifier |
| Statement number | ✅ | `:28C:` statement / sequence number |
| Currency | ✅ | Extracted from opening balance field |
| Opening balance | ✅ | `:60F:` / `:60M:` — date and amount |
| Closing balance | ✅ | `:62F:` / `:62M:` — date and amount |
| Transaction list | ✅ | Date, amount (signed), reference (first 20) |
| Multiple statements | ✅ | Multi-statement files parsed correctly |
| FIN envelope stripping | ✅ | SWIFT FIN wrapper removed before parsing |
| Source view | ✅ | Monaco editor (plaintext mode) |
| Diff | ❌ | Disabled — financial data diff not meaningful |
| Metadata | ✅ | Account, currency, balance, transaction count |

| Capability | Status | Notes |

## Known Limitations

- `:86:` narrative lines (transaction descriptions) are not shown
- Only first 20 transactions displayed in preview
