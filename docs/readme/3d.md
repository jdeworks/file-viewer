# 3D Models

> Interactive 3D model viewer with orbit and mesh coloring controls — renders STL, OBJ, PLY, glTF/GLB, and 3MF client-side.

## Format Details

| Format | Extensions | Common use |
|--------|-----------|-----------|
| STL | `.stl` | 3D printing, CAD export |
| OBJ | `.obj` + `.mtl` | General-purpose mesh exchange |
| PLY | `.ply` | Point clouds, scan data |
| glTF / GLB | `.gltf`, `.glb` | Web 3D, games, AR/VR |
| 3MF | `.3mf` | 3D printing with color and materials |

## Capabilities Matrix

### View
| Capability | Status | Notes |
|------------|--------|-------|
| Canvas mesh preview | ✅ | Orbit via mouse / touch; mesh is auto-fit to the viewport |
| Auto-fit | ✅ | Model scaled and centered on load |
| Selection coloring | ✅ | Region, face, and group color modes |
| Colored PLY download | ✅ | Exports current mesh colors from the preview toolbar |
| OBJ download | ✅ | Preview toolbar can download an OBJ copy |
| Triangle / vertex count | ✅ | Shown where the format parser exposes it |
| Bounding box dimensions | ✅ | Size in model units displayed in the preview summary |
| OBJ source view | ✅ | OBJ is text — Monaco editor + text diff available |
| glTF JSON source view | ❌ | glTF/GLB route is preview-only |
| GLB binary | ❌ | Raw view not available for binary GLB |
| STL / PLY / 3MF raw view | ❌ | Binary formats — no raw text view |
| Metadata | ✅ | Triangle count, vertex count, material count, bounding box |

### Edit
| Capability | Status | Notes |
|------------|--------|-------|
| OBJ source editing | ✅ | Full Monaco editor on OBJ text |
| Preview color edits | ✅ | Temporary in-browser coloring for inspection/export |

| Capability | Status | Notes |
|------------|--------|-------|

## Known Limitations

- Textures in OBJ (MTL references) are not loaded — models appear as simple colored geometry
- Animations in glTF are not played back
- Very large meshes (>1M triangles) may be slow to parse and render
- No lighting beyond a fixed ambient + directional light setup
