What the ZIP viewer supports

  • A navigable listing of archive folders and entries.
  • Entry sizes, compression information, and archive metadata.
  • Opening supported files from inside the archive.
  • Local extraction and export tools, including supported password flows.

Privacy and limitations

The archive is inspected locally in the default flow. Available memory limits very large archives, and unsupported encryption or damaged directory records can prevent some entries from opening.

File Viewer also recognizes several other archive and binary container formats. Browse the format guides.
