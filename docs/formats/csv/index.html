CSV and TSV viewer

View and edit CSV files locally

Open comma-, tab-, semicolon-, or pipe-delimited data as an interactive table while keeping the source available for editing and comparison.

Open File ViewerChoose a CSV or TSV after the viewer opens.

What the CSV viewer supports

  • Automatic or manual delimiter selection.
  • Header-row controls and a structured table preview.
  • Source editing, formatting, and original-versus-current diffs.
  • Export to JSON or Excel-compatible XLSX.

Privacy and limitations

The file is parsed in your browser in the default flow. Very large tables remain subject to the memory and performance limits of the browser and device.

For other structured data, see the JSON viewer, YAML viewer, or XLSX viewer.
