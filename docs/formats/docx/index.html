What the DOCX viewer supports

  • Local extraction and presentation of document content.
  • Common headings, paragraphs, lists, tables, links, and images.
  • Document metadata inspection.
  • A focused browser view for reading and reviewing content.

Privacy and limitations

The DOCX package is opened locally in the default flow. Exact Word pagination, advanced layout, macros, embedded objects, and application-specific features may not reproduce like desktop Microsoft Word.

Also open Excel workbooks, PowerPoint presentations, and PDF documents.
