PPTX viewer

Preview PowerPoint presentations locally

Open Microsoft PowerPoint PPTX files as navigable slides in the browser without first sending the presentation to an online conversion service.

Open File ViewerChoose a PPTX file after the viewer opens.

What the PPTX viewer supports

  • Slide-by-slide presentation navigation.
  • Adjustable rendering scale.
  • Common text, images, shapes, and presentation layouts.
  • Presentation metadata and notes inspection where available.

Privacy and limitations

The presentation package is processed locally in the default flow. Animations, transitions, media, uncommon fonts, and advanced PowerPoint effects may be simplified or unavailable.

Also open Word documents, Excel workbooks, and PDF files.
