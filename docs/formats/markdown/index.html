What the Markdown viewer supports

  • Syntax-aware source editing and live rendered preview.
  • A visual WYSIWYG editing mode.
  • Original-versus-current and move-aware diffs.
  • Formatting, screenshots, and document export options.

Privacy and limitations

The document is rendered locally by default, and unsafe embedded HTML is sanitized. Following links or deliberately allowing external document resources can still create ordinary network requests.

Need raw structured data instead? Open the JSON viewer or YAML viewer.
