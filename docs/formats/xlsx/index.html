XLSX viewer

Open Excel workbooks locally

Browse Microsoft Excel XLSX sheets in an interactive grid and export table data without sending the workbook to a hosted viewer.

Open File ViewerChoose an XLSX file after the viewer opens.

What the XLSX viewer supports

  • Sheet selection and an interactive cell grid.
  • Common cell values, formulas, formatting, comments, and links.
  • Workbook metadata inspection.
  • Export of sheets or selections to CSV and JSON.

Privacy and limitations

The workbook is parsed locally in the default flow. Macros are not executed, and advanced Excel features, external data connections, or application-specific formatting may not be reproduced exactly.

For plain table data, use the CSV viewer. Other Office formats include DOCX and PPTX.
