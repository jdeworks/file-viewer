What the XML viewer supports

  • Syntax-aware source editing and formatting.
  • A structured preview of elements, attributes, and text.
  • Original-versus-current text and structural comparisons.
  • Metadata and export tools appropriate to the document.

Privacy and limitations

XML parsing happens in your browser in the default flow. The viewer does not replace schema-specific validation tools, and external references are not fetched automatically as part of ordinary local viewing.
