What the PDF viewer supports

  • Interactive page navigation and adjustable render scale.
  • Document metadata inspection.
  • Text extraction and page-image export when the PDF permits it.
  • Password entry for supported encrypted documents.

Privacy and limitations

The selected PDF is processed locally in the browser in the default viewing flow. Complex forms, scripts, unusual fonts, encryption, or damaged files may render differently from a dedicated desktop PDF application.
