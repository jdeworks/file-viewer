* Design Notes

** Architecture

The system follows a component tree model inspired by React. Each widget
is an immutable value object; mutations produce new trees.

#+BEGIN_SRC python
from widgets import App, VBox, Button

def on_click():
    print("clicked!")

app = App(
    root=VBox([
        Button("Click me", on_click=on_click),
    ])
)
app.run()
#+END_SRC
