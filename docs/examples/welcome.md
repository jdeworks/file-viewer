# Welcome to File Viewer

A **mobile-first**, private file viewer. In default browser mode, files are processed
without uploads, accounts, analytics, or telemetry; app requests stay same-origin.

## What it does

- Auto-detects the file type and picks the right view
- Shows **raw** (Monaco editor) and a **rendered preview** side by side
- On phones, raw and preview live in separate tabs
- Supports editing, comparison, metadata inspection, and download
